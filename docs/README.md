# Trading Bot 가이드 문서

이 프로젝트는 암호화폐 시장 데이터를 실시간으로 수집하고, 수집된 데이터를 바탕으로 트레이딩 전략을 시뮬레이션(백테스트)하거나 실거래를 수행할 수 있는 고성능 트레이딩 봇 프레임워크입니다.

## 🚀 프로젝트 요약
`trading-bot`은 Binance Futures 및 Alternative.me(Fear & Greed Index) 등 다양한 소스로부터 시장 데이터를 수집하여 고성능 시계열 데이터베이스인 QuestDB에 저장합니다. 또한, 헥사고날 아키텍처를 기반으로 설계되어 유연한 확장성을 제공하며, 저장된 과거 데이터를 기반으로 전략을 검증하는 백테스팅 엔진과 실거래를 집행하는 트레이더 기능을 포함합니다.

## 🏗️ 핵심 아키텍처 요약
본 프로젝트는 **헥사고날 아키텍처(Hexagonal Architecture)**를 채택하여 코어 로직과 외부 시스템을 엄격히 분리합니다.

- **Domain**: 외부 환경에 의존하지 않는 핵심 비즈니스 규칙과 엔티티를 포함합니다.
- **Application**: 유즈케이스(수집기, 백테스터, 트레이더)를 조율하고 비즈니스 흐름을 제어합니다.
- **Ports**: 애플리케이션이 외부와 상호작용하기 위한 인터페이스를 정의합니다.
- **Adapters**: 거래소 API, 데이터베이스 등 외부 시스템과 포트를 연결하는 구체적인 구현체입니다.

이러한 구조를 통해 코드의 테스트 용이성을 확보하고, 새로운 거래소나 데이터베이스를 손쉽게 추가할 수 있는 유연성을 제공합니다.
